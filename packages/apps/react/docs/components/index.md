# Component Index

Use root named imports by default. Category named imports expose same APIs.
Individual paths, where listed, are default imports. A dash means no public
individual default export exists.

## Theme APIs

Import `ThemeProvider`, `createTheme`, and `useTheme` from `@iziui/react` or
`@iziui/react/theme`. Start with [getting started](../getting-started.md).

## Advanced APIs

`Bounce`, `Fade`, `Slide`, `Zoom`, `useResize`, `useListenerResized`, and
`useAccessibleDialog` have dedicated public subpaths. Read
[Advanced APIs](./advanced.md) before using them.

## Experimental APIs

`@iziui/react/lab` exports `Form`, `useForm`, `useControl`, `useFormGroup`,
`FormGroup`, `FormControl`, `createControl`, and related form types. These APIs
are experimental. Read [Advanced APIs](./advanced.md) and obtain explicit
project approval before use.

## Prop Types

Root and category imports export prop types beside their components, for
example `ButtonProps`, `StackProps`, `GridProps`, and `TypographyProps`.
Use editor type information for the full native HTML attribute surface after
reading the component guide for selection and composition guidance.
