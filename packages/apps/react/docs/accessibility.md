# Accessibility Navigation

iziUI provides component-level semantics, keyboard behavior, focus handling,
and ARIA relationships where a component owns that behavior. Applications
remain responsible for complete accessible user flows.

Read the full [Accessibility Guide](../ACCESSIBILITY.md) before using:

- Input, Select, Autocomplete, CheckboxGroup, InputFile, or validation messages.
- Drawer, Modal, Menu, custom dialog triggers, or focus management.
- Alert, Toast, Loading, Progress, or other asynchronous feedback.
- Icon-only actions, custom controls, heading hierarchy, and color-based status.

Test keyboard navigation, screen-reader announcements, zoom, contrast, error
recovery, and focus behavior in the consuming application.
